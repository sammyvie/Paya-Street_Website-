Paya Street Café Website

// Authors: Canlas, Marc; Gonzales, Robyn; Gonzales, Samantha Wayne; Mangalino, Kurt Justine
// GitHub: https://github.com/Marc-WD/Final-Paya-Street-Website

Overview

- A responsive website for Paya Street Café that:
- Shows menu items and featured products
- Lets users submit messages via a contact form
- Includes email and social media marketing mockups
- Uses live API data and Google Maps integration

Quick Start

* Clone the repo: "git clone https://github.com/Marc-WD/Final-Paya-Street-Website.git"
* Go to folder: "cd Final-Paya-Street-Website"
* Install dependencies: "npm install"
* Start project: "npm start"
* Open browser at: "http://localhost:3000"
